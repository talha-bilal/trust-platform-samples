2. My technical approach

I operate on-prem Keycloak in production today (Dictalabs): AD/LDAP federation, OIDC application SSO, realm lifecycle, and custom SPI where required. The customer engagement follows the same proven pattern.

Delivery target architecture — same model I run in production; demo available for your pre-sales calls.

Principles I follow on every phase

  • AD stays master — no duplicate user database unless agreed
  • Production Keycloak config (PostgreSQL, TLS) — not dev-mode in go-live
  • Per-application UAT sign-off before production cutover
  • Realm export + DB backup before each major change
  • Written handover so your team can support after my engagement

3. Phase-by-phase delivery plan

Aligned to your customer approval scope (Phases 1–6). I estimate 22–24 billable days over 4–6 calendar weeks.

1

Discovery & design ~3 days

  • Join kickoff with customer IT and app owners (remote)
  • Validate AD topology, LDAPS path, 8-app protocol matrix (OIDC vs SAML)
  • Produce technical design: realm, federation, firewall matrix, cutover plan
  • Output: design doc you can attach to customer pack
2

Platform deployment ~4 days

  • Install Keycloak + PostgreSQL on customer VMs (Docker or native per agreement)
  • TLS, admin RBAC, brute-force, session timeouts, logging
  • Smoke test and initial backup baseline
3

Active Directory / LDAPS ~3 days

  • Configure user federation (bind account, search bases, sAMAccountName/UPN)
  • Group → role mappers; sync up to 300 users
  • Test valid login, disabled account, group change
4

MFA configuration ~2 days

  • TOTP authenticator policy (baseline per scope)
  • Pilot with IT users; admin reset procedure documented
5

Application SSO — 8 apps ~10 days

  • Per app: client registration, metadata/redirect URIs, claims, logout
  • Support app owner UAT; fix mapping issues
  • Apps per scope: Dynamics, ServiceDesk Plus, Endpoint Central, portal, Temenos, Tookitaki, SAS, +1 TBD
6

Testing & handover ~2 days

  • Regression: AD + MFA + SSO; backup/restore drill
  • Administrator guide, implementation notes, remote KT session (half day)
  • Support your customer sign-off call if needed
